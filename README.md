# dotinoproject

Compilation of Arduino Projects

## Projects

- [LED Blink](projects/led_blink.ino) - Basic LED blinking circuit with customizable delay intervals.
- [Temperature Sensor](projects/temperature_sensor.ino) - Reads temperature data from DHT11 sensor and displays on serial monitor.
- [Servo Motor Control](projects/servo_motor_control.ino) - Controls servo motor position using potentiometer input.
- [LCD Display](projects/lcd_display.ino) - Displays custom text messages on 16x2 LCD screen.
- [Ultrasonic Distance Sensor](projects/ultrasonic_distance.ino) - Measures distance using HC-SR04 ultrasonic sensor module.
